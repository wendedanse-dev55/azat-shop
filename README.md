# Azat Shop 🛍️

Интернет-магазин на **Next.js 15** (App Router) с категориями, корзиной,
админ-панелью и импортом товаров из **Excel**.

Дизайн: фирменная **ледяная синяя** палитра (в тон логотипу-снежинке), UX маркетплейса в стиле
**Ozon** (поиск в центре шапки, кнопка «Каталог», карточки со скидками и
рейтингом, фильтры и сортировка, buy-box на странице товара, степперы количества,
нижняя навигация на мобильных).

## Возможности

- **Витрина**: главная с промо-баннером, каталог категорий, страницы категорий
  с **фильтрами** (цена, наличие) и **сортировкой**, полнотекстовый **поиск**,
  карточка товара с buy-box, корзина (сохраняется в браузере).
- **Скидки и рейтинг**: старая цена → бейдж «−%», звёзды рейтинга и число отзывов.
- **Админ-панель** (`/admin`): дашборд, создание/редактирование/удаление
  товаров с загрузкой изображений, управление категориями.
- **Импорт из Excel**: загрузка `.xlsx`, автосоздание категорий, обновление
  товаров по артикулу, скачивание готового шаблона.

## Стек

- Next.js 15 + React 19 + TypeScript
- Tailwind CSS v4
- Prisma + PostgreSQL (Neon) — база в облаке, работает на serverless
- Vercel Blob — хранилище загруженных изображений в проде
- ExcelJS (чтение/генерация Excel)

## Быстрый старт

Нужна база PostgreSQL. Проще всего — бесплатный проект на [Neon](https://neon.tech):
создайте его и скопируйте строки подключения в `.env` (см. `.env.example`).

```bash
cp .env.example .env # затем впишите DATABASE_URL и DIRECT_URL от Neon
npm install          # установка зависимостей + prisma generate
npm run db:push      # создать таблицы в базе
npm run db:seed      # заполнить демо-данными (категории и товары)
npm run dev          # запустить http://localhost:3000
```

Магазин: <http://localhost:3000>
Админка: <http://localhost:3000/admin> — пароль по умолчанию **admin123**

## Настройка

Все настройки — в файле `.env`:

| Переменная             | Назначение                                                    |
| ---------------------- | ------------------------------------------------------------- |
| `DATABASE_URL`         | Postgres, **пулинг**-строка (хост с `-pooler`) — рантайм        |
| `DIRECT_URL`           | Postgres, **прямая** строка (без `-pooler`) — для `db push`     |
| `BLOB_READ_WRITE_TOKEN`| токен Vercel Blob (в проде ставится сам; локально можно пусто)  |
| `ADMIN_PASSWORD`       | пароль для входа в админку                                      |
| `AUTH_SECRET`          | секрет для подписи cookie сессии (смените!)                     |

Валюта задаётся одной константой `CURRENCY` в [`lib/format.ts`](lib/format.ts)
(по умолчанию `₸`).

## Импорт Excel

Колонки шаблона (заголовки в первой строке, регистр и язык не важны — понимает
русские и английские варианты):

`Название` (обязательно), `Цена`, `Старая цена`, `Категория`, `Описание`,
`Остаток`, `Артикул`, `Рейтинг`, `Отзывы`, `Изображение`.

- Категории, которых ещё нет, создаются автоматически.
- Если указан `Артикул` и товар с ним уже существует — товар **обновляется**,
  иначе создаётся новый.

Готовый шаблон можно скачать в админке: **Импорт Excel → Скачать шаблон**.

## Деплой на Vercel

1. **База — Neon.** Создайте бесплатный проект на [neon.tech](https://neon.tech).
   Понадобятся две строки подключения: пулинг (`-pooler`) и прямая.
2. **Импорт в Vercel.** Залейте код в GitHub → на [vercel.com](https://vercel.com)
   *Add New → Project* → выберите репозиторий (фреймворк Next.js определится сам).
3. **Blob для картинок.** Вкладка *Storage → Create → Blob* — привяжите к проекту.
   Переменная `BLOB_READ_WRITE_TOKEN` добавится автоматически.
4. **Переменные окружения** (*Settings → Environment Variables*):
   `DATABASE_URL`, `DIRECT_URL`, `ADMIN_PASSWORD`, `AUTH_SECRET`.
5. **Deploy.** Сборка (`vercel-build`) сама выполнит `prisma db push` и создаст
   таблицы. Демо-данные можно один раз залить локально: указать в `.env` строку
   Neon и выполнить `npm run db:seed` — либо просто добавить товары через админку.

Ограничения бесплатного тарифа (Hobby): только некоммерческое использование;
загрузка файла через форму — до ~4.5 МБ (лимит тела запроса serverless-функции).

## Заметки

- Загруженные изображения: в проде — в **Vercel Blob** (публичные URL), локально —
  в папке `./uploads` (отдаётся через `/api/uploads/[file]`). Ветка выбирается по
  наличию `BLOB_READ_WRITE_TOKEN` — см. [`lib/actions.ts`](lib/actions.ts).
- Авторизация в админке — простая (пароль + cookie), рассчитана на один аккаунт.
  Для продакшена усильте (полноценные сессии/хеширование).
